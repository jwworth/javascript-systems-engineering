# JavaScript Systems Engineering

An exploration of systems engineering tools in JavaScript for an upcoming Maine
JS Meetup. This code is experimental and is for demonstration purposes only.

## Tasks to explore

1. Git clone and other Git commands
1. Fetch a file from remote server
1. Untar and build
1. Linting
1. Autoformatting
1. Unit testing
1. Perform operation via SSH
1. SSH key forwarding for jumping to another host

## Setup

For the NPM directory, install Node and npm. Then:

```
cd npm/
npm install
```

Any command in `package.json` under `scripts` is available to explore.
